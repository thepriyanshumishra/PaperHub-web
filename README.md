# 📄 PaperHub

> **"A premium university exam preparation environment."** — Designed to feel like VS Code for exam prep.

PaperHub is a university-focused, structured exam preparation platform built for **descriptive/written university examinations**. It transforms scattered PDFs, WhatsApp PYQs, and random Drives into a topic-wise, syllabus-aware preparation hub powered by **Groq AI** step-by-step solutions.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🎓 **Syllabus-Aware Structure** | Prep mapped to semesters → branches → subjects → units → topics |
| 💡 **AI Step-by-Step Solutions** | University-standard solutions generated by Llama-3.3-70b via Groq |
| 🔍 **Explain This Step** | Wide modal with two-column layout — step context on the left, AI breakdown on the right |
| 📝 **Exam / Practice Mode** | Practice mode (unlimited hints) and Test mode (distraction-free, timed) |
| 💬 **Syllabus Doubts Assistant** | Persistent AI chat drawer scoped to the current subject and question |
| 🎨 **Cozy Design System** | Warm `#FFF8F4` light mode + `#121212` dark mode, optimised for long study sessions |
| 🔢 **Math + Code Rendering** | KaTeX for equations, Prism syntax highlighting for C / C++ / Python code |
| 🗄️ **MongoDB Persistence** | Cached AI solutions — solve once, read instantly on repeat visits |

## 🚀 Getting Started

### 1. Prerequisites
- [Node.js](https://nodejs.org/) v18+  
- A [MongoDB Atlas](https://www.mongodb.com/atlas) cluster (free tier works fine)  
- A [Groq API key](https://console.groq.com/) (free tier, very fast)

### 2. Clone & Install
```bash
git clone https://github.com/thepriyanshumishra/PaperHub-web.git
cd PaperHub-web
npm install
```

### 3. Environment Variables
Create `.env.local` in the project root:
```env
MONGODB_URI=mongodb+srv://<user>:<password>@<cluster>.mongodb.net/paperhub?retryWrites=true&w=majority
GROQ_API_KEY=gsk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

### 4. Seed the Database
Populate your Atlas cluster with colleges, branches, subjects, units, and past-year questions:
```bash
npx tsx scripts/seed.ts
```

### 5. Start the Dev Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) and complete onboarding to start practising.

## 🤖 AI Integration

All AI features use **Groq's Llama-3.3-70b-versatile** model:

| Route | Purpose | Caching |
|---|---|---|
| `GET /api/ai/solve` | Generate full step-by-step solution for a real DB question | ✅ Stored in MongoDB (`question.cachedSolution`) |
| `POST /api/ai/solve` | Generate solution for a mock/local question | ❌ No cache |
| `POST /api/ai/explain-step` | Deep breakdown of a single solution step | ❌ Always live |
| `POST /api/ai/chat` | Syllabus-scoped conversational Q&A | ❌ Always live |

### Prompting Rules
- Solutions are instructed to use **university exam answer style** (not olympiad shortcuts)  
- Code blocks must use **fenced markdown ` ``` `** with language identifier — never LaTeX `\quad` inside code  
- Mathematical equations use **`$$...$$`** LaTeX notation rendered via KaTeX

### Clearing Stale Cache
If AI responses contain formatting artefacts (e.g. `\quad` in code blocks), clear all cached solutions and let them regenerate:
```bash
npx tsx scripts/clearCache.ts
```

## 🗄️ MongoDB Notes

- Connection uses `autoSelectFamily: false` to force IPv4 and avoid TLS handshake failures in Next.js server routes on some Node.js versions.  
- The Mongoose connection is a **singleton** cached on the Node.js global object to survive Next.js hot-reload.
- Atlas Network Access must whitelist your IP (or `0.0.0.0/0` for development).
